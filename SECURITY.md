# Security Policy

## Supported Versions

`agnara-execution-runtime` is an educational historical reference application (#005) frozen at `agnara==0.1.0a3`.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.0   | :white_check_mark: |

Because this repository contains pure in-memory Python domain structures and does not expose network ports or external listeners, operational security risks are minimal.

## Reporting a Vulnerability

If you discover a security issue or vulnerability in Agnara Core or this reference application, please report it privately:
- Through GitHub: [Security Advisory](https://github.com/agnara-project/agnara-execution-runtime/security/advisories)
- Or via email: security@agnara.dev

Please include reproduction steps and environment details. We acknowledge receipt within 48 hours.
